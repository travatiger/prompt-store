PromptHub PRO ALL-FEATURES (bugfixed build)

1. Keep a backup of your currently working PromptHub first.
2. Upload the ZIP contents directly to your GitHub/Vercel project root.
3. IMPORTANT: In Supabase SQL Editor, run ONCE, in this order:
   a) supabase/2026-09-20-PRO-FEATURES.sql
   b) supabase/2026-09-20-BUGFIX-PATCH.sql   (new — required for real view counts / ratings on the storefront)
4. Do NOT rerun the older COMPLETE-FREE-PAID-PAYMENT-MULTIMEDIA.sql if your current database is already working. It is included as a reference/backup only.
5. Hard-refresh the site after deployment.

--- Fixes in this build ---
- product.html was calling loadReviews()/loadRelated(), two functions that
  did not exist anywhere in the file. This threw a JavaScript error on every
  product page and silently stopped ALL page setup after it — meaning no
  product ever rendered, and no one could view or buy a prompt. Both
  functions are now implemented for real (reviews list + average rating +
  review submission, and a related-prompts grid).
- The Favorite, Share, Export, and Gift/Share buttons on the product page
  existed in the HTML but had no click handlers at all — clicking them did
  nothing. All four are now wired up (Favorite toggles via localStorage,
  Share/Gift use the native share sheet with a clipboard fallback, Export
  downloads the unlocked prompt as a .txt file).
- Storefront cards always showed "0 views / 0.0 rating" and the "Popular"
  sort never worked, because the homepage never fetched any stats and the
  raw view-log table is admin-only by design. Added a public, aggregate-only
  RPC (get_public_product_stats) so real counts show up without exposing
  any raw/sensitive rows.

MARKETPLACE UPGRADE
===================
1. Back up the Supabase database.
2. Run marketplace_migration.sql once in Supabase SQL Editor.
3. Keep the existing Binance Pay configuration; seller payouts are manual through the seller payout request flow.
4. Upload all website files, including seller.html and seller-profile.html.
5. Existing admin-owned products remain approved. Seller products are draft/pending until an admin approves them.
6. The public seller profile URL is seller-profile.html?username=USERNAME.
7. Never expose a Supabase service_role key in frontend files.
